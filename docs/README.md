# Engineering documentation

This is the independent VehicleParkingSystem repository. Documentation describes
the source at this checkpoint, not a claim of commercial readiness.

- [Current phases 3–4 implementation](PHASE_3_4.md): runnable identity and parking
  APIs, exact setup/test commands, updated architecture and transaction sequences.

The documents below preserve the earlier phase 1–2 checkpoint. Read the current
phase 3–4 reference for features that have since been implemented.

- [Architecture and data model](ARCHITECTURE.md): running components, boundaries,
  database relationships, API and deployment decisions.
- [Sequence diagrams](SEQUENCE_DIAGRAMS.md): current execution paths and separately
  labeled future authentication, parking and realtime workflows.
- [Software design](SOFTWARE_DESIGN.md): relevant concepts, their implementation,
  tradeoffs and remaining work.
- [Review and verification](REVIEW_AND_VERIFICATION.md): scope, evidence and gaps.

For exact commands see [README](../README.md); for plain-language testing see
[HOW_TO_TEST](../HOW_TO_TEST.md). Diagrams use Mermaid and render on GitHub.
